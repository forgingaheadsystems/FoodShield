# FoodShield

FoodShield is an early-stage project intended to provide a suite of digital
tools for food pantries at “100% no cost.” That phrase is an unresolved
operational term whose origin and limits are recorded in the glossary. The
project's intended scope begins with needs reported in Sundermeir et
al., “Current Use and Demand for Digital Tools to Enhance Food Pantry
Management: Findings from a Nationwide Survey.” No application architecture,
module boundaries, or implementation stack has been approved or built yet.

## Current repository status

This repository currently establishes project context, terminology authority,
external terminology mappings, and source preservation. It does not currently
contain application code or establish compliance with any regulation, funding
program, or industry standard.

## Terminology provenance

FoodShield records distinguish source terminology, agent-proposed terminology,
owner-approved FoodShield terminology, and unresolved terminology. An
agent-proposed adaptation, compound, conjugation, or normalized form is
identified even when its underlying words are established elsewhere.

## Git workflow

The owner-approved direction is to use a short-lived branch for each coherent
change, review the exact diff, open a pull request, and merge into `main` only
after review. Direct development on `main` is not the intended workflow.
